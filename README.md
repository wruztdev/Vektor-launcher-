# 📺 Vektor Launcher TV

**Vektor Launcher TV** is a minimalist, closed-source launcher built specifically for Android TV. Designed to provide the fastest, lightest, and most distraction-free experience possible.

## ✨ Key Features

*   🚀 **Ultra Lightweight:** Built 100% in pure Java with zero external dependencies. The APK is incredibly small.
*   🎨 **Clean Interface:** No ads, no movie recommendations, no bloatware. Just your apps on an elegant black background.
*   🕹️ **Optimized for Remote Controls:** Smart button mapping. The "Back" button on your remote acts as a click for the selected app.
*   ⌨️ **Keyboard Shortcuts:** Support for physical keyboards (F1 for settings, M for menu, B for search, G for Google).
*   ⏱️ **Integrated Clock and Date:** Bottom taskbar with the current time and date, updated efficiently.

## 🛠️ Tech Stack

*   **Language:** Java
*   **Compatibility:** Android TV (API 21+)
*   **UI Design:** 100% programmatic (no XML for main views)

## 📦 Installation

You can download the APK directly from the [Releases](link-to-your-releases) section of this repository.

1. Download `VektorLauncher.apk` to your TV or phone.
2. Install it (you will need to allow installation from unknown sources).
3. Press the "Home" button on your remote and select Vektor as your default launcher.
