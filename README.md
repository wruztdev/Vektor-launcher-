# Vektor Launcher TV

A clean, lightweight launcher designed for Android TV. Vektor focuses on giving your installed apps a simple home screen without recommendation feeds, advertising, or unnecessary visual clutter.

<p align="center">
  <strong>Android TV · Java · Remote-friendly interface</strong>
</p>

## Features

- **App library:** Displays apps installed on the device with their names and icons.
- **Quick launch:** Select an app to open it.
- **App management shortcut:** Long-press an app card to open that app's Android settings.
- **Remote navigation:** Interface focus states and navigation designed for a TV remote.
- **Custom wallpaper:** Choose a desktop background; the selected wallpaper is saved and restored after restarting the launcher.
- **Quick menu:** Access wallpaper selection, About Vektor, desktop reload, and Android settings.
- **Clock and date:** A bottom taskbar displays the current time and date.
- **Home screen integration:** Supports the Android Home role on compatible Android versions.

## Compatibility

- **Platform:** Android TV
- **Language:** Java
- **Minimum Android version:** API 21+ (Android 5.0)
- **Interface:** Primarily built programmatically; the main views do not rely on XML layouts.

Vektor is designed for television screens and remote controls. Behaviour may vary between Android TV devices and firmware versions.

## Download and install

The latest published GitHub release is currently **V1.5**.

[**Download Vektor Launcher V1.5**](https://github.com/wruztdev/Vektor-launcher-/releases/download/V1.5/Vektor-v1.5.apk) · [All releases](https://github.com/wruztdev/Vektor-launcher-/releases)

1. Download the APK on your Android TV device.
2. Allow installation from the source you used to download the APK, if Android asks.
3. Install Vektor.
4. Press the Home button and choose Vektor as your preferred launcher.

> **Version 2.0:** Development and testing have progressed beyond the currently published V1.5 release. V2.0 is not listed as a public GitHub release yet. This page will be updated when its APK is published.
