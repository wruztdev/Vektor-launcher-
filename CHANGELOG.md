# Changelog

Notable changes to Vektor Launcher TV are documented here.

## [2.0] - In development / testing

The 2.0 update has been built and tested, but it has **not yet been published as a GitHub release**.

- Added wallpaper selection.
- The selected wallpaper is saved and restored after restarting the launcher.
- Added a quick menu with wallpaper selection, About Vektor, desktop reload, and Android settings.
- Improved the app home screen experience with large app cards and remote-friendly focus feedback.
- Added long-press access to an installed app's Android settings.
- Retained the bottom clock and date display.
